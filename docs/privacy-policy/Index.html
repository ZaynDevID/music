Kebijakan Privasi

Berlaku sejak 2 November 2026 · Diperbarui 2 November 2026

Ringkasnya: Musik adalah pemutar audio offline. Aplikasi tidak memiliki akun, iklan, analytics, atau izin internet. File musik dan data perpustakaanmu tetap di perangkatmu dan tidak dikirim ke mana pun.

1. Siapa yang mengelola aplikasi ini

Aplikasi Musik (paket com.zayndev.music) dikembangkan dan diterbitkan oleh ZaynDev. Pertanyaan tentang privasi dapat disampaikan melalui tombol Email pengembang pada halaman resmi aplikasi di Google Play.

2. Data yang diakses

  • File audio di perangkat. Dengan izinmu, aplikasi membaca file audio dari penyimpanan perangkat atau folder yang kamu pilih agar dapat menampilkan dan memutarnya.
  • Pengaturan aplikasi. Tema, pengaturan equalizer, timer, dan pilihan tampilan disimpan secara lokal.
  • Playlist dan impor folder. Daftar lagu yang kamu susun atau impor disimpan secara lokal di penyimpanan aplikasi.
  • Log crash. Jika aplikasi mengalami error, ringkasan teknis (termasuk model perangkat dan versi Android) dapat ditulis ke folder aplikasi dan/atau Downloads/Musik. Log ini tidak dikirim otomatis dan hanya ada di perangkatmu.

Aplikasi tidak mengakses kontak, lokasi, kamera, mikrofon, atau riwayat penjelajahan.

3. Izin yang digunakan

  • READ_MEDIA_AUDIO (Android 13+) dan READ_EXTERNAL_STORAGE (Android 12 ke bawah): membaca file audio.
  • POST_NOTIFICATIONS: menampilkan kontrol pemutaran di notifikasi.
  • FOREGROUND_SERVICE dan FOREGROUND_SERVICE_MEDIA_PLAYBACK: menjaga musik tetap diputar saat aplikasi di latar belakang.
  • WAKE_LOCK dan MODIFY_AUDIO_SETTINGS: menjaga pemutaran stabil dan mengatur audio.

Izin hanya diminta saat diperlukan dan dapat dicabut kapan saja melalui pengaturan Android.

4. Pengumpulan dan pembagian data

Kami tidak mengumpulkan, menjual, menyewakan, atau membagikan data pribadi. Aplikasi tidak menggunakan SDK iklan, analytics, pelacakan, atau layanan pihak ketiga yang mengirim data. Tidak ada data yang dikirim ke server kami karena aplikasi tidak memiliki koneksi internet.

5. Penyimpanan dan penghapusan

Data perpustakaan, playlist, dan pengaturan disimpan di perangkat sampai kamu menghapus data aplikasi atau menghapus instalasinya. File audio asli tidak diubah atau dihapus oleh aplikasi. Log crash di Downloads/Musik dapat kamu hapus sendiri melalui pengelola file.

6. Keamanan

Karena data tidak dikirim keluar perangkat, risikonya terutama bergantung pada keamanan perangkatmu. Kami menyarankan menjaga kunci layar dan mencadangkan file musik penting secara terpisah.

7. Anak-anak

Aplikasi ini bukan layanan yang ditujukan khusus untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data pribadi anak. Aplikasi hanya memutar file audio yang sudah ada di perangkat atau yang dipilih pengguna.

8. Tautan ke situs lain

Menu Kebijakan Privasi di aplikasi membuka halaman ini melalui browser. Jika kamu membuka tautan lain, kebijakan privasi situs tersebut berlaku. Aplikasi tidak mengirim data ke browser.

9. Perubahan kebijakan

Jika praktik data berubah, halaman ini akan diperbarui dan tanggal di bagian atas akan diubah. Versi terbaru selalu tersedia di alamat ini.

10. Kontak

Untuk pertanyaan, koreksi, atau permintaan terkait privasi, gunakan tombol Email pengembang pada halaman Google Play aplikasi Musik. Kami akan menanggapi melalui saluran yang tersedia di listing tersebut.
